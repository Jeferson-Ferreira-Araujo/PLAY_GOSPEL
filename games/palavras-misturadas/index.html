Como jogar

Escolha a categoria e o tempo. Inicie o jogo. Uma palavra (ou frase) aparecerá com as letras embaralhadas. O jogador precisa descobrir antes do tempo acabar. Quando as palavras acabarem, o jogo encerra.

Configurações

Se o tempo acabar, troca automaticamente de palavra.

Dicas

  • Funciona bem ao ar livre usando tela cheia.
  • Frases com espaços (ex: “Atos dos Apóstolos”) também embaralham.
  • Use “Mostrar resposta” se estiver usando em grupo.
  • Espaço: próxima palavra • F: tela cheia
